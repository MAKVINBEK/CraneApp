# CraneApp - Secure Messenger with Official Bot

## 🚀 Features

- **Real-time Messaging** - WebSocket-based instant messaging
- **Groups & Channels** - Create communities and broadcast channels
- **CraneApp Bot** - Official bot for security notifications and support
- **Media Sharing** - Photos, videos, voice messages, files
- **Voice & Video Calls** - WebRTC-powered calls
- **End-to-End Encryption** - Secret chats with E2EE
- **Cross-Platform** - Mobile and Desktop support
- **Cloud Sync** - Messages synced across all devices

## 🛠️ Tech Stack

- **Backend**: Node.js, Express, WebSocket
- **Database**: PostgreSQL, Redis
- **Frontend**: Vanilla JS, HTML5, CSS3
- **Deployment**: Docker, Railway

## 📦 Installation

```bash
# Clone repository
git clone https://github.com/craneapp/craneapp.git
cd craneapp

# Install dependencies
npm install

# Copy environment file
cp .env.example .env

# Edit .env with your configuration

# Start development server
npm run dev

# Start production server
npm start
